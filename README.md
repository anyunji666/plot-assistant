# 剧情助手

不依赖「酒馆助手」插件，直接使用 SillyTavern 原生扩展接口。包含四块功能，共用同一本按"角色名 + 总结"命名的世界书：

- **总结/状态表**（总结功能）
- **对话前强调**（输出强调）
- **创建角色**（角色卡）
- **地图标记**

## 可选安装方法

1. 找到你的酒馆数据目录下的 `data/<你的用户名>/extensions/` 文件夹
   （比如 `SillyTavern/data/default-user/extensions/`）。
2. 把整个 `plot-assistant` 文件夹复制进去，得到：
   `data/<你的用户名>/extensions/plot-assistant/manifest.json`
   `data/<你的用户名>/extensions/plot-assistant/index.js`
   `data/<你的用户名>/extensions/plot-assistant/style.css`
   `data/<你的用户名>/extensions/plot-assistant/lib/leaflet/...`
3. 重新加载酒馆网页（或在"扩展"面板点刷新）。
4. 打开扩展菜单（顶部三个格子的图标），应该能看到「剧情助手」一项，点开即弹出控制面板。

## 总结功能（总结/状态表）

面板"总结功能"分组下三个按钮：**自动小总结**（按当前对话进度，每30层自动往后总结，支持起始楼层偏移，见下）、**设定起始楼层**（沿用同一本总结世界书新开对话继续写时，设定本对话的楼层号从第几层开始编号）、**自动大总结**（把所有小总结整合成一段主线脉络）。

- 总结世界书按"角色名 + 总结"命名，与角色卡绑定的世界书无关，不存在会自动创建。
- 状态表：解析每层输出的摘要模块，持久化 Relationships / Inventory / Setups 三项。
- **起始楼层会记到"本对话"的 chatMetadata 里**（跟着这个对话/存档走，重新打开同一个对话不会丢；换到别的对话、别的角色卡也不会互相干扰）。只有你再次点击"设定起始楼层"并确认新值时，才会覆盖这个记录——只是重新打开这个对话、不主动点按钮，数字不会变。
- 面板"总结功能"按钮下方有一行只读展示"本对话当前起始楼层"，打开面板时读取，不可编辑，方便随时确认当前生效值，不用再靠点开"设定起始楼层"弹窗去看。
- "设定起始楼层"弹窗里预填的建议值，每次都是**实时重新扫描世界书**算出来的（历史最大止楼层 + 1，世界书为空则是 0），不会用本对话已经保存的值当默认值——避免世界书内容变了、但默认值还停留在旧建议上。
- **自动小总结会自动读取本对话的起始楼层**：没设置过就是 0（不偏移）；设置过就会把新写入的世界书条目楼层号统一加上这个偏移量，读取原始聊天记录仍然用本对话内部的楼层号，只是世界书里保存的标题楼层号变了。不需要区分"是不是接续对话"，一个按钮通用两种场景。
- **典型用法**：总结完一段故事、重置角色卡或新开一个对话继续写、但仍沿用同一本总结世界书时，先点一次"设定起始楼层"（弹窗会自动扫描世界书里已有的历史小总结、预填建议的起始楼层，一般直接确认即可），再照常用"自动小总结"往后总结。
- 批次内如果有楼层没输出摘要模块，会调用AI针对这些楼层逐层还原 Time/Location/Overview（用户发言楼层不参与、不需要还原），还原结果和正常楼层的摘要字段一起拼成小总结内容，这一步本身不再经过AI。
- 自动小总结运行时可以点"停止总结"，会在当前还未开始的还原调用之前生效，已经保存的批次不受影响。

（详细规则和已知注意事项参见代码内注释。）

## 输出强调（对话前强调）

面板"输出强调"分组下的**对话前强调**按钮：手动维护一条固定提示内容（默认是摘要输出格式协议），内容 + 启用开关，保存后立即写入总结世界书，跟总结/状态表同级存在。

## 角色卡（创建角色）

面板"角色卡"分组下的**创建角色**按钮，弹出"角色名 + 其他信息"表单，写入内容会包成：

```
<character_information character="角色名">
其他信息...
</character_information>
```

- 存放位置：和总结/状态表共用同一本"角色名总结"世界书，标题固定加**「角色卡：」**前缀（如"角色卡：欧阳雨柔"）。
- 触发方式：关键词触发（非常驻），关键词按人名自动提取全名 + 去姓简称（如"欧阳雨柔"会同时以"欧阳雨柔"和"雨柔"触发），只有正文提到这个人名才会注入上下文，省 token。
- 编辑/删除：不需要单独入口，新建的角色卡条目会和小总结/大总结/状态表一样出现在面板下方的"世界书条目"列表里，展开即可直接改正文或删除；改变正文里的 `character="..."` 不会自动重新提取关键词/改标题，需要的话删掉重建。
- 重名：同一个角色名只能存在一条，新建时如果标题已存在会报错，提示你去世界书条目列表里直接编辑那一条。

## 地图标记

- **数据按角色区分**：不需要"绑定某个角色卡"，地图数据（标记点、路线、势力、小地图）自动跟随当前打开的角色卡，切换角色卡即切换到该角色自己的地图数据，互不干扰。群聊或没有选中角色卡时，地图数据只临时存在本地，不会同步进任何世界书。
- **注入方式为世界书条目**：地图内容会自动写入当前角色的"角色名总结"世界书里，固定标题为**「地图信息」**的一条条目，跟"小总结/大总结/状态表/对话前强调"同级存在，默认位置设置与小总结/大总结相同。这条条目的内容由插件自动生成和覆盖（不可手动编辑正文），但**条目本身是否启用要在世界书面板里自己控制**——新建的世界书需要你手动加入全局启用列表或绑定到当前角色/聊天。
- **触发时机**：每次编辑标记、路线、小地图说明/是否加载后，以及切换角色卡时，都会自动重新生成并覆盖这条「地图信息」条目。
- **入口**：只有两个入口，打开的是同一个地图编辑器：
  - 剧情助手控制面板里，"地图"分组下的**「地图标记」**按钮
  - 右下角悬浮球（可拖拽记忆位置；PC 端默认常显，移动端窄屏不显示，不提供开关）
- **"清除数据"范围**：地图编辑器里的"清除当前角色的地图数据"只清除当前角色的标记/路线/图片，不会影响其他角色的地图数据。

### 使用方式

- 大地图（唯一，世界地图）：标记点 + 势力行动路线。点击地图任意位置添加标记；点"添加路线"后依次点击两个已有标记，填写方位、队伍信息与时间即可生成一条路线。
- 小地图（可多张，村庄/庄园/房间等）：标记点 + 手写的"布局关系/特别说明"，勾选"加载到本次对话的 AI 上下文"决定是否计入「地图信息」。
- 标记/路线数据支持导出导入 JSON（不含图片，图片需重新上传）。
- Leaflet 库文件本地打包在 `lib/leaflet/`，不依赖外网。
